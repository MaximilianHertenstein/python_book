## Übungen im Python-Playground

Bearbeite die folgenden Aufgaben im Python-Playground.

### 1. Vorhersage → Ausführen

Schreibe zuerst das Ergebnis auf. Führe dann den Code aus und überprüfe deine Vermutung.

``` python, py-execute
xs = ['a', 'b', 'c']
xs[1]
```

### 2. Verändere die Eingabe

Ändere nur den Index, sodass `'c'` ausgegeben wird.

``` python, py-execute
xs = ['a', 'b', 'c']
xs[1]
```

### 3. Ergänze die Lücke

Ergänze die Lücke, sodass `ys` aus `xs` und einem zusätzlichen Element `'d'` besteht.

``` python, py-execute
xs = ['a', 'b', 'c']
ys = ____
ys
```

### 4. Fehler finden und reparieren

Der Code erzeugt einen IndexError. Ändere den Index so, dass ein gültiges Element ausgegeben wird.

``` python, py-execute
xs = ['a', 'b', 'c']
xs[3]
```

### 5. Prüfe deine Idee

Sage voraus, was in jeder Zeile ausgegeben wird, bevor du den Code ausführst.

``` python, py-execute
xs = [1, 2, 3]
for x in xs:
    print(x * 2)
```
