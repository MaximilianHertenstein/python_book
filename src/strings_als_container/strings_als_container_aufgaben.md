## Übungen im Python-Playground

Bearbeite die folgenden Aufgaben im Python-Playground.

### 1. Vorhersage → Ausführen

Schreibe zuerst das Ergebnis auf. Führe dann den Code aus und überprüfe deine Vermutung.

``` python, py-execute
'python'[2]
```

### 2. Verändere die Eingabe

Ändere nur den Index, sodass der letzte Buchstabe von `'python'` ausgegeben wird.

``` python, py-execute
'python'[2]
```

### 3. Fehler finden und reparieren

Der Code erzeugt einen IndexError. Ändere den Index, sodass ein gültiger Buchstabe ausgegeben wird.

``` python, py-execute
'cat'[3]
```

### 4. Ergänze die Lücke

Ergänze die Lücke, sodass die Schleife alle Buchstaben von `word` einzeln ausgibt.

``` python, py-execute
word = 'code'
for i in range(0, ____):
    print(word[i])
```

### 5. Prüfe deine Idee

Sage voraus, welchen Buchstaben der Ausdruck ergibt, bevor du ihn ausführst.

``` python, py-execute
('good' + 'bye')[3 + 2]
```
