## Übungen im Python-Playground

Bearbeite die folgenden Aufgaben im Python-Playground.

### 1. Vorhersage → Ausführen

Schreibe zuerst das Ergebnis auf. Führe dann den Code aus und überprüfe deine Vermutung.

``` python, py-execute
message = 'Das Ergebnis ist: '
number = 5
message + str(number)
```

### 2. Fehler finden und reparieren

Der Code erzeugt einen TypeError. Ergänze die fehlende Typumwandlung.

``` python, py-execute
message = 'Die Zahl ist: '
number = 7
message + number
```

### 3. Verändere die Eingabe

Ändere nur den String, sodass `int(...)` die Zahl `42` ergibt, statt einen Fehler zu erzeugen.

``` python, py-execute
int('hello')
```

### 4. Ergänze die Lücke

Ergänze die Lücke, sodass `text` den Satz mit dem Wert von `age` korrekt zusammensetzt.

``` python, py-execute
age = 12
text = 'Ich bin ' + ____ + ' Jahre alt.'
text
```

### 5. Prüfe deine Idee

Vergleiche die beiden Ausdrücke und erkläre den Unterschied.

``` python, py-execute
3 * 'ab'
```

``` python, py-execute
'3' * 'ab'
```
