## Übungen im Python-Playground

Bearbeite die folgenden Aufgaben im Python-Playground.

### 1. Fehler finden und reparieren

Ergänze das fehlende Zeichen, sodass beide Funktionen fehlerfrei definiert sind.

``` python, py-execute
def double(x: int) -> int:
    return 2 * x

def square(x: int) -> int
    return x * x
```

### 2. Fehler finden und reparieren

Der Code erzeugt einen `IndentationError`. Ergänze die fehlende Einrückung.

``` python, py-execute
def cube(x: int) -> int:
return x * x * x

cube(3)
```

### 3. Vorhersage → Ausführen

Lies den Code genau. Sage voraus, in welcher Zeile der Fehler gemeldet wird, bevor du ausführst.

``` python, py-execute
def half(x: int) -> int:
    return x // 2

def triple(x: int) -> int
    return x * 3
```

### 4. Ergänze die Lücke

Ergänze das fehlende Zeichen an der Lücke, sodass der Funktionskopf gültig ist.

``` python, py-execute
def add_one(x: int) -> int:
    return x + 1

def subtract_one(x: int) -> int____
    return x - 1
```

### 5. Prüfe deine Idee

Ändere den Doppelpunkt in Zeile 1 in ein Semikolon (`;`) und führe den Code aus. Notiere, welche Zeile und welches Zeichen Python in der Fehlermeldung nennt.

``` python, py-execute
def double(x: int) -> int:
    return 2 * x
```
