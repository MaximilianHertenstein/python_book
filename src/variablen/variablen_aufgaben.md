## Übungen im Python-Playground

Bearbeite die folgenden Aufgaben im Python-Playground.

### 1. Vorhersage → Ausführen

Welchen Wert hat `y` am Ende? Schreibe zuerst deine Vermutung auf und überprüfe sie danach.

``` python, py-execute
x = 4
y = x
x = 10
y
```

### 2. Verändere die Eingabe

Ändere nur den Wert von `feet_per_yard`, sodass `yards_in_feet` am Ende den Wert `40` hat.

``` python, py-execute
feet_per_yard = 3
yards_in_feet = feet_per_yard * 10
yards_in_feet
```

### 3. Fehler finden und reparieren

Der folgende Code erzeugt einen SyntaxError. Korrigiere den Variablennamen, ohne die Zahl darin zu entfernen.

``` python, py-execute
2nd_number = 5
2nd_number
```

### 4. Ergänze die Lücke

Ergänze die Lücke, sodass `area` die Fläche eines Quadrats mit der Seitenlänge `side` berechnet.

``` python, py-execute
side = 4
area = ____
area
```

### 5. Prüfe deine Idee

Berechne zuerst per Hand, welchen Wert `result` nach jeder Zeile hat. Führe den Code danach aus.

``` python, py-execute
result = 0
result = result + 5
result = result + result
result
```
