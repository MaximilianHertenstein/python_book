## Übungen im Python-Playground

Bearbeite die folgenden Aufgaben im Python-Playground.

### 1. Vorhersage → Ausführen

Schreibe zuerst das Ergebnis auf. Führe dann den Code aus und überprüfe deine Vermutung.

``` python, py-execute
7 / 2
```

### 2. Verändere die Eingabe

Ändere nur eine Zahl, sodass das Ergebnis genau `5.0` ist.

``` python, py-execute
10 / 2
```

### 3. Ergänze die Lücke

Ergänze die Lücke, sodass `number_int` die abgerundete Ganzzahl von `number_float` enthält.

``` python, py-execute
number_float = 7.9
number_int = ____
number_int
```

### 4. Fehler finden und reparieren

Der Code erzeugt einen TypeError. Ergänze die fehlende Typumwandlung.

``` python, py-execute
price = 19.99
count = '3'
price * count
```

### 5. Prüfe deine Idee

Sage voraus, ob das Ergebnis exakt ist, bevor du ausführst.

``` python, py-execute
0.1 + 0.2
```
